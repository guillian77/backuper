# Unraid - Backuper

Allow you to manage directories to save in one or multiple targets.

## Features

Available features:
- schedule backup period
  - hourly
  - daily
  - monthly
  - year
- purge old backups
  - choose retention delay in days
- encrypt backup (Age needed)
- Monitor backup/purge history

## Install

1. Go to plugin page
2. Select plugin tab
3. Type:
```
https://raw.githubusercontent.com/guillian77/backuper/master/plugin/backuper.plg
```
5. Click install
